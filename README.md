# KEIBA PROOF

競馬動画の画面内テロップを日本語OCRで読み取り、誤字・競馬用語の修正候補を確認するサイトです。字幕ファイルのテキスト校正も利用できます。

## 起動

Node.js 22 以降を使用します。

```sh
cd /workspace/-
npm ci
npm start
```

既定のポートは3000です。`PORT`で変更できます。開発時は`npm run dev`を使用します。`npm ci`のpostinstallで、Tesseract・日本語/英語モデルの固定済み依存関係から`public/vendor/ocr`へ配信用アセットをコピーします。`npm run prepare:ocr`で再生成できます。

## 動画内のテロップを確認

1. 「動画テロップ」で動画を選びます。MP4（H.264）・WebMなど、使用するブラウザで再生できる形式に対応します。MOV等の対応はコーデックとブラウザによります。
2. テロップの場所を指定します。画面下部35%・下半分・全体、または左・上・幅・高さの割合で設定できます。
3. 「この画面を読む」で現在のフレームだけOCRできます。「テロップを読み取る」では指定範囲を0.5・1・2・5秒間隔で処理します。一度の実行は最大600フレームです。長い動画は範囲を区切ってください。
4. 切り出し画像・時刻とOCR結果を見比べます。OCRの読み間違いを先に編集してから、辞書に基づく修正候補を適用・無視できます。OCRスコア70未満の結果を絞り込めます。スコアは正しさの保証ではありません。
5. CSVで確認レポートを保存します。元のOCR結果・修正後テキスト・時刻・残っている候補を含みます。必要なら「テキスト校正へ」でSRTへ転記し、書き出せます。終了時刻はサンプリング間隔に基づく概算です。

同じ文字が連続するフレームはまとめます。空白フレームを挟んだ同じテロップは別として扱います。停止しても抽出済みの結果は残ります。

動画・切り出し画像・テキストは外部に送信しません。Tesseract.js 6.0.1とロックされたCore、日本語・英語モデルを自分のサーバーから配信し、Web Worker内で処理します。ブラウザがWebAssemblyとWeb Workerを許可している必要があります。APIキー・DB・有料サービスは不要です。通常のWeb版はGoogle Fontsを利用しますが、OCR処理には外部サービスを使用しません。

## インストール不要の体験版

```sh
npm run build
```

`dist/keiba-proof.html`を生成します。HTMLにOCRエンジン・モデル・ライセンスも同梱します。ファイルをダウンロードしてデスクトップのChrome/Edge等で開くと、サーバーや外部アセットの読み込みなしで使う構成です。ブラウザや端末がローカルHTMLのJavaScript・Blob Workerを制限している場合は、Web版を利用してください。JRA用語集リンクを開く場合のみインターネット接続が必要です。

管理環境のブラウザではfile://ナビゲーションが制限されているため、配布版HTMLの検証はローカルHTTPレスポンスとして同じドキュメントを読み込み、外部アセット通信なしで実OCR・校正まで実行しています。端末上でのfile://起動は未検証です。

## Webサイトとして公開する場合

GitHub Pages用のワークフローを`.github/workflows/pages.yml`に用意しています。公開の実行には利用者の承認とGitHub側の設定・権限が必要です。設定ファイルを作っただけでは、公開されません。

1. GitHubリポジトリのSettings → PagesでSourceに「GitHub Actions」を指定します。
2. サイトのソースをmainブランチに保存すると、依存導入・テスト・単一HTML生成・Pagesへの配置を行います。
3. GitHub Actionsの「Deploy site」に出力された実際のURLで、動画を選択してOCRを実行します。配置先のURLを確認するまでは公開完了と扱わないでください。

`dist/index.html`は単独で配信でき、リポジトリ名を含むサブパスにも対応します。動画・画像は端末内で処理され、GitHubに送信しません。

## テスト

```sh
npm test
```

辞書校正、サンプリング範囲・件数制限、画像の切り出し座標、タイムコード、SRT・CSVの出力を検証します。実ブラウザでも日本語テロップ入り動画でOCR→「復勝」から「複勝」の修正候補→CSV保存まで検証しています。

## 範囲と制限

- 音声の文字起こしではなく、映像内の文字を読むOCRです。動画の焼き込みテロップを修正して再エンコードする機能はありません。映像の修正は動画編集ソフトで行ってください。
- 指定間隔より短いテロップ、フェード・アニメーション、装飾文字、小さい文字、縦書き等は見落とし・誤認識があります。全文を保証するチェックではありません。
- 校正は`public/checker.js`とユーザー辞書に登録されたルールの照合です。AIの文脈校正、最新の馬名・騎手名DBとの照合、JRAの監修・用語集の自動取り込みはありません。
- [JRA競馬用語集](https://www.jra.go.jp/kouza/yougo/)への参照リンクを設けています。公式の表記や意味を確認して、必要なルールをユーザー辞書に登録してください。
- ユーザー辞書とテキスト校正の本文を含まない履歴のみlocalStorageに保存します。動画・OCR結果・編集本文は再読み込みで失われます。レポートを保存してから閉じてください。
- TXT・SRT・VTT（UTF-8、50,000文字以内）も読み込めます。既存のタイムコードを保って文字を修正します。
